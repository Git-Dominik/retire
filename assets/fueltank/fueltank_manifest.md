# MSH_Industrial_FuelTank_A

Built to DOORS_ASSET_GUIDE v20 (Mines biome, all parts crisp, no soft parts, no hand-made wonk).
Skid-mounted fuel tank: 8-sided shell, saddles, end ladder, manway, vents, two gauges, a level sight tube and a red-handwheel outlet valve.
Size about 4.6 x 6.2 x 11.5 (W x H x L) studs, pivot bottom centre. Front is -Z in Roblox. 1,920 triangles in total.
