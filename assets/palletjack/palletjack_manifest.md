# MSH_Industrial_PalletJack_A

Built to DOORS_ASSET_GUIDE v20 (Mines biome, all parts crisp, no soft parts, no hand-made wonk).
Red hand pallet truck: forks with load rollers, sloped body, pump with spring, steer wheels, tiller, faceted handle loop with grips and release trigger.
Size about 2.0 x 4.3 x 5.6 studs, pivot bottom centre. Front is -Z in Roblox. 912 triangles in total.
